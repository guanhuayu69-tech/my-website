# 普健堂中医官网 v4：极简冲击版

## 本轮设计目标

将原先“长页面 + 多组小卡片”的表达，重构为少量但更强的空间场景。页面不再依靠堆信息制造丰富感，而通过大图、留白、字号反差、明暗切换和清晰动线建立层次。

## 首页五层结构

1. **空间首屏**：一句品牌主张、一个主行动、一个次行动。用诊所空间证明审美与信任。
2. **三项价值**：一人一案、四诊合参、持续随访。把品牌差异压缩为三件能记住的事。
3. **AI 咨询主场景**：将真实可用的 8 次咨询产品放到深绿色大场景里，不再作为普通内容卡片。
4. **问题—服务—方法**：用纵向问题索引、三步服务路径、四诊合参解释用户下一步。
5. **人物与到店转化**：诊疗理念、健康笔记、地址、电话和微信形成可信闭环。

## 借鉴的顶级网站布局套路

- Parsley Health：首屏只讲一个核心结果与一个主要行动，随后展示照护旅程和服务选项。
- Function Health：先给出单一主张与行动，再用三步流程和长期追踪解释产品价值。
- Mayo Clinic：主行动明确，下面按“用户下一步”组织内容和资源，而不是按机构部门堆砌。
- Headspace：按用户任务与收益分层，将数字助手放在成熟服务体系中，而不是孤立展示技术。
- Aesop：空间设计强调克制、材料、地方语境与安静感，避免用装饰性豪华制造高端。

本项目只吸收信息架构、视觉节奏和转化逻辑，不复制第三方图片、品牌、商标或原文。
